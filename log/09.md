오늘 결정한 것 : 내가 만든 분류 모델 3개의 정확도와 F1 점수 등을 확인하고 기준선과 비교해 어떤 모델이 좋은지 판단하기로 했다.

AI에게 보낸 프롬프트(원문) : 내가 만든 모델의 평가 지표를 확인하고, 결과를 베이스라인과 비교하여 해석하고 main.py의 모델 평가에 작성하려고해.

AI가 준 것 중 고치거나 버린 것과 그 이유 : 처음에는 모델의 점수가 나와도 그 결과가 무엇을 의미하는지 알기 어려웠다. 그래서 기준선보다 얼마나 좋은지 설명하고 최종 모델을 선정한 이유도 추가하도록 했다. 수정 과정에서 코드 오류도 발생해 다시 수정하도록 요청했다.

느낀 점 : 세 모델의 성능을 비교해 보니 정확도가 가장 높은 모델과 F1 점수가 가장 높은 모델이 달랐다. 모델을 평가할 때 한 가지 점수만 보는 것이 아니라 여러 지표를 확인해야 한다는 것을 알게 되었다.

AI 없이 내가 스스로 한 것 : 스트림릿에서 기준선과 세 모델의 평가 결과를 직접 확인하고 화면을 보내 비교와 해석을 요청했다.
