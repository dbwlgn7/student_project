오늘 결정한 것 : 기존 모델의 성능을 높이기 위해 데이터 전처리 방법을 바꿔 다시 학습하고 기존 결과와 비교하기로 했다.

AI에게 보낸 프롬프트(원문) : 이제 모델성능을 개선시키려고해. 평가 지표를 바탕으로, 모델의 성능을 개선하기 위한 데이터 전처리를 수행하고 모델을 다시 학습시킵니다. 이 과정을 수행하지 않은 경우 내 데이터가 학습에 적합했는지, 모델의 성능이 해당 데이터 내에서 충분한 결과를 가지는지 근거를 작성합니다.

개선된 결과는 새로운 탭(성능 개선)을 만들어 main.py에 추가합니다.

AI가 준 것 중 고치거나 버린 것과 그 이유 : AI가 제안한 방법은 학년과 겹치는 학교급을 제외하고 이용 매체 개수라는 변수를 추가하는 것이었다. 기존 모델과 비교할 수 있도록 성능 개선 탭을 추가한 코드를 받았다. 다만 실제 성능이 좋아졌는지는 아직 확인하지 못했다.

느낀 점 : 데이터를 전처리하는 방법에 따라 모델의 성능이 달라질 수 있다는 것을 알게 되었다. 하지만 전처리 방법을 바꿨다고 무조건 성능이 좋아지는 것은 아니므로 실제 결과를 비교하는 것이 중요하다고 생각했다.

AI 없이 내가 스스로 한 것 : 기존 모델의 성능을 개선해 보겠다는 방향을 정하고, 개선 전후 결과를 비교하는 탭을 추가하도록 직접 요청했다.
